# サバイバー経験値計算アイコン

組み込みimage_genを使用。透過背景を指定し、生成PNGのアルファを保持して `tool-survivor-xp.png` にコピーした。

最終プロンプト:

```text
Use case: stylized-concept. Asset type: one transparent square UI icon for the Survivor XP Calculator in a Japanese ARK Manager game companion app. Primary request: create a clear, polished game inventory icon that communicates a human survivor gaining experience. Subject: a small brushed-metal calculator with a simple glowing upward arrow and a compact human survivor bust symbol on its screen; one subtle amber experience star. Style: premium semi-realistic 3D game item render, cohesive with a dark navy ARK-inspired app using cyan/turquoise highlights. Composition: single centered compact object, large readable silhouette at 64px, front three-quarter view, generous transparent padding about 8%, no surrounding tile or backdrop. Materials: dark gunmetal, cyan light, warm amber accent. Constraints: genuinely transparent background, crisp edges, no lettering, no numerals, no watermark, no logos, no extra objects.
```
