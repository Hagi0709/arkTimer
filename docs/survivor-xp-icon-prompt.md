# サバイバー経験値計算アイコン

組み込みimage_genを使用。透過背景を指定し、生成PNGのアルファを保持して `tool-survivor-xp.png` にコピーした。

最終プロンプト:

```text
Use case: logo-brand. Asset type: replacement UI icon for a survivor experience calculator, displayed at 48–64 pixels in a dark navy app. Primary request: make an extremely simple, flat EXP icon. Composition: one plain dark navy rounded square (#122B3D), with only the exact uppercase text "EXP" centered inside it. Typography: bold, wide, clean sans serif capital letters, bright cyan (#66D9E8), very legible at small size, large enough to fill most of the tile with comfortable margins. Spell the text exactly E X P, shown as EXP. Two solid colors only, crisp clean edges. The area outside the rounded square must be truly transparent. Avoid: any calculator, character, person, arrows, stars, numbers, illustrations, patterns, gradients, textures, glow, highlights, shadows, 3D, borders, extra text, watermarks. Keep the design as simple as possible.
```
