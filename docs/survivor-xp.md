# サバイバー経験値計算

「ツール」タブから専用アイコン付きのツールカードを選び、開始レベルと目標レベルを入力する。Lv1〜245に対応し、必要経験値は目標レベルの累計XPから開始レベルの累計XPを引く。両方とも各レベルに到達した直後として扱い、レベル途中の獲得分は含めない。同じレベルは0XP、逆順・空欄・小数・範囲外は入力エラーとする。レベルごとの必要XPと開始レベルからの合計も確認できる。

データはユーザーが2026-11-02に貼り付けた[Wikilyの経験値表](https://wikily.gg/ja/ark-survival-ascended/xp-calculator)の245行。`data/survivor-xp.tsv` に「0始まりの番号・到達レベル・累計XP」の3列を保持する。ユーザーの指定により、画面上のゲーム名・計算前提の説明・マルチプレイヤーや上限解放の注意書き・参照リンクは表示しない。

ビルド時に `scripts/prepare-survivor-xp.mjs` で行数・連番・安全な整数・累計の増加を検証し、配信用の `survivor-xp-data.js` を生成する。補間・丸めや32ビット整数変換をせず、Lv151→152の32XPなども元表どおり保持する。計算と画面表示はブラウザー内で行い、入力値をサーバーへ送信しない。

確認例：Lv1→105は4,098,538XP、Lv100→105は2,300,000XP、Lv220→245は3,021,372,928XP、Lv1→245は7,975,037,952XP。自動テストで245行すべての照合、差分・内訳・入力エラー、ツール画面の往復、3タブとキーボード操作を確認する。今回の環境ではブラウザーが利用できず、実機の画面確認は未実施。

アイコンは組み込みimage_genで生成したシンプルな「EXP」の文字のデザイン。成果物は `tool-survivor-xp.png`。生成プロンプトは `docs/survivor-xp-icon-prompt.md`。
